# HP3 EU Core binding and startup config audit

8 November 2026. Source follow-up to the phone report from 0.4.14. These changes are not yet in the published 0.4.14 APK.

The seven Core functions are a small part of UE2 support. The Hardware2Options.ini failure is in class-config initialization, independent of these functions. Missing native mesh/terrain classes and other UE2 systems remain separate work.

## Trace results

The exact twelve script packages bundled in 0.4.14 were inspected. All 8,090 function schemas parse without errors. For each of the seven declarations, argument order, scalar/struct types, return property, array dimensions and native index are checked against EU Core.u. Package hashes, declarations and call sites are in HP3-SEVEN-CORE-TRACE.json; no retail game bytes are included there.

| Binding | EU native index | Execution checks and findings |
| --- | --- | --- |
| Acos | 0, by name | Float input/return slots and -1, 0, 0.5, 1 inputs pass. |
| Asin | 0, by name | Same checks; resolved script call in kwgame.kwherocontroller.playersliding.handleslidejump. |
| Greater_StrStr | 116 | Lexicographic comparison, equality and empty string; production BitfieldBool writes preserve unrelated bits. |
| GetLastStateName | 285 | Receiver/return slots; production GotoState body tested for initial, changed, unchanged, cleared and reentrant states, plus UE1 isolation. |
| QuatProduct | 0, by name | Noncommuting products, repeated rotation and output slots. Resolved script call in engine.svehicle.specialcalcview. Found and fixed the missing const-quaternion VM conversion. |
| QuatRotateVector | 0, by name | Vector return and radian rotation; inputs remain unchanged. Shares the corrected const-quaternion conversion. |
| QuatFromAxisAndAngle | 0, by name | Radian angle and normalized nonzero axis; zero axis now returns identity rather than dividing by zero. This is a defined degenerate-input safeguard, not a claim that the original PC binary was tested on that input. |

Native index 0 denotes name dispatch, not absence of a binding. No direct calls to five of the seven functions were found in this script corpus. That is not proof they are unreachable through runtime lookup, console use, or native code. Named-call matches, if any, are marked as candidates requiring receiver resolution.

## Implemented repairs

1. Add ExpressionValue::ToType<const quaternion&>() forwarding to the production ToQuat conversion. Previously the generic reference conversion required ValueStruct, while these arguments are ValueQuat. Matching declaration signatures did not detect this integration failure.
2. Use a PoA axis-angle wrapper with a zero-axis guard. Keep the prior normalized-axis/radian convention for nonzero input; do not change U227 globally.
3. Allow absent auxiliary PoA class-config files to initialize an empty INI model with its intended path. UClass::LoadProperties then retains serialized defaults for absent keys. Apply case-insensitive file lookup and save modified auxiliary configs through UpdateIfExists. Do not create files merely by reading them; preserve existing files and propagate errors reading existing paths. System/User and other games retain strict loading.

The corpus names 28 class-config namespaces. Many optional debug/options INIs are absent from the original bundle, including Hardware2Options, HardwareOptions, MeshOptions, TerrainOptions and others listed in the JSON. System and User are special aliases, and UnrealEd.ini is generated by the launcher; absence from the disc inventory does not establish absence on the phone. The general auxiliary-config repair avoids a filename-by-filename workaround.

## Validation and limits

- 110 host tests run: 109 passed, one optional original-data regression skipped. The new test file has three compiled ASan/UBSan harnesses.
- Production Core bodies and VM adapter templates execute with production conversion methods/specializations and BitfieldBool. ExpressionValue storage/registry, UObject storage and other surrounding services are test doubles. This is not a full production VM or game session.
- The production GotoState body is exercised with simulated classes, frames and callbacks; complete save/load persistence and Android execution remain unverified.
- The production INI constructor is exercised for absent optional, absent strict, existing-content and existing-directory cases. Source review covers strict alias routing and auxiliary save destinations; Android filesystem behavior remains unverified.
- Host C++20 syntax checks pass for PoaCore.cpp, IniFile.cpp and PackageManager.cpp using engine include paths.
- The follow-up canonical patch was applied to the retained original engine files and reproduced all four edited engine files byte for byte.
- ARM64 rebuilding and phone startup validation are separate checks. No APK or playability claim is made by this audit. The source lock for the previous release remains historical until a new full-source checkpoint is packaged.

Reproduce with function_schemas.py GAME OUTPUT, audit_core_seven.py GAME/system OUTPUT/trace.json, and unittest discovery under native-runtime/tools/poa. The supplied phone report verifies progress past CompanionCombatManager to UDebugMenu.UGraphHardware2Page; it does not establish rendering or gameplay.
