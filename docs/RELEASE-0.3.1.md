# Harry Potter TQ 0.3.1

HP1 and HP2 HD texture modules are embedded in the APK and remain optional via the existing launcher HD textures option, saved independently per game. HP1 has 3,505 refreshed textures and HP2 has 3,697. The bundle includes all six categories for each game.

Missing or empty Default.ini and DefUser.ini are repaired before launch. Existing nonempty configurations and saves are preserved. Chamber of Secrets original data is included; HP1 uses an existing installation/import. Prisoner of Azkaban is greyed out and not playable.

Install over the previous app, preserving the package ID and signing key. APK size: 1,802,688,326 bytes. Allow room for extraction and HD staging. Build, signature, native-library identity and host checks passed; real-device gameplay testing remains pending.

This draft currently preserves complete source, checksums, installation notes and verification. APK and standalone HD release assets are pending upload. Signing key and password are intentionally excluded.
